# FocusGuard

## Идея
Во время учебы дети часто отвлекаются на телефоны, идея проекта в том, чтобы фиксировать и сообщать ребенку или родителю об этом.

## MVP
Телефон находится в руке не менее двух секунд.

## Как определяется телефон в руке
Камера получает картинку, YOLO определяет границы предмета (телефон, например), далее подключается MediaPipe и определяет ключевые точки кисти руки, затем InteractionDetector уже строит по ним расширенную область и проверяет близость либо пересечение с рамкой телефона, после чего активируется таймер (по умолчанию 2 секунды, параметр настраиваемый), по истечении которого будет появляться красная рамка вокруг телефона.

## Архитектура
```
Camera ─┬→ YOLO ──────┐
        └→ MediaPipe ─┴→ InteractionDetector → HoldTimer → Renderer
```

## Стек
Python 3.11, OpenCV, Ultralytics YOLO, MediaPipe, NumPy, pytest.

## Критерии готовности
- [ ] камера открывается и показывает изображение;
- [ ] телефон и кисть визуально отмечаются;
- [ ] таймер запускается только при контакте телефона с областью кисти;
- [ ] через две секунды появляется красная рамка и PHONE IN HAND;
- [ ] при потере контакта состояние и таймер сбрасываются;
- [ ] обработка выполняется локально.

## Не входит в MVP
Уведомления, журнал событий, другие предметы, собственное обучение модели.

## Обработка ошибок
Камера недоступна или модели не загрузились — программа сообщает причину и корректно завершается.

## Тестирование
Отдельно проверяются геометрия контакта и логика двухсекундного таймера.
